# 🍹 Fizzi - 3D Animated E-Commerce Landing Page 🚀

### Designed & Developed by [Abhranil Dutta](https://my-portfolio-abhranil-dutta.netlify.app/)  

Welcome to **Fizzi**, an immersive **3D animated** e-commerce landing page built for a fictional soda brand! This project combines **stunning visuals, smooth animations, and modern UI/UX** to create an engaging web experience.  

---

## 🌟 Features  

✅ **3D Animated Products** - Experience interactive product visualization  
✅ **Smooth GSAP Transitions** - Dynamic and engaging animations  
✅ **Prismic CMS Integration** - Easy content management  
✅ **Next.js & Tailwind CSS** - Lightning-fast performance & modern design  
✅ **Fully Responsive** - Optimized for all devices  

---

## 🚀 Get Started  

### **1️⃣ Clone the Repository**  
```sh
git clone https://github.com/your-username/fizzi-website.git
cd fizzi-website
```

### **2️⃣ Install Dependencies**  
```sh
npm install
```

### **3️⃣ Set Up Prismic CMS**  
- Create a **[Prismic account](https://prismic.io/)**
- Open your **Prismic repository** and select **"English - United States"**  

### **4️⃣ Load the Content**  
```sh
npm run set-up-content
```

### **5️⃣ Run the Project**  
```sh
npm run dev
```
> Open [http://localhost:3000](http://localhost:3000) in your browser
